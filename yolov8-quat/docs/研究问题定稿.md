## 0. 先纠正一处理解反了的地方

你说："**四元数被验证的只是在色温偏移上有用**"

**这是反的。** 准确情况是：

| | 状态 |
|---|---|
| **亮度 / 对比度变化** | ✅ **文献验证过四元数类层更鲁棒**（Moya-Sánchez 2021，但其 M6 层**不是**标准四元数卷积） |
| **色温 / 白平衡偏移** | ❌ **没有任何人做过实验**；而且**我的理论推导表明它没有内建不变性**（见 `论证链与文献支撑.md` 2.5.2） |
| **均匀亮度缩放** | ⚠️ 四元数卷积能"吸收"，但**普通卷积同样能**（都是线性算子）→ **不构成优势** |

**所以更准确的说法是**：

> **四元数卷积在"光照"这件事上，目前没有任何一条被验证过的、独有的优势。**

文献里唯一沾边的是 M6 对**对比度**的鲁棒性 —— 而 M6 是 monogenic signal 层，不是标准四元数卷积。

**这不是坏消息，这恰恰是你的机会** —— 见第 2 节。

## 1. 你的困惑："验证假设" vs "提升模型" —— 它们不是两条路

**关键认识：它们是一张表格的两个方向，不是二选一。**

### 1.1 你要做的全部实验，就是下面这 6 个格子

```
训练数据 = PlantDoc 源域（强光+阴天）的真实图  +  可选的合成图
测试数据 = 真实数据（源域 held-out + 目标域 逆光/傍晚）  ← 固定不变
```

| 训练数据 ↓ \ 网络 → | **普通 MobileNet** | **四元数 MobileNet** |
|---|---|---|
| **S0** 只用真实数据 | ① | ② |
| **S1** + 合成图（只换背景） | ③ | ④ |
| **S2** + 合成图（换背景 **且** 光照迁移） | ⑤ | ⑥ |

### 1.2 两个方向，回答两个不同的问题

| 比较方向 | 比什么 | **回答什么问题** |
|---|---|---|
| **横向**（①vs②, ③vs④, ⑤vs⑥） | 同一份训练数据下，两种网络 | **验证假设**：四元数有没有用？ |
| **纵向**（①→③→⑤, ②→④→⑥） | 同一个网络下，三种训练数据 | **提升模型**：合成增强有没有用？ |

**它们在表格的不同方向上，互不干扰。** 这就是为什么它们不矛盾。

**你原来的困惑来源**：以为要"选一条路走"。实际上你是要**填满这张 6 个格子的表**。

### 1.3 三种合成策略：不是三选一，是三种训练数据配置

| | 做什么 | 补的是什么 | 为什么需要它 |
|---|---|---|---|
| **S0** | 不合成，直接用真实 PlantDoc 源域图 | —— | **基线**，没有它无法判断合成有没有用 |
| **S1** | PlantVillage 叶片贴到 PlantDoc 背景上，**不做光照匹配** | **背景多样性** | 分离出"背景多样"这一项的贡献 |
| **S2** | 在 S1 基础上，把**叶片的光照调成与背景一致** | **光照多样性 + 光照一致性** | **这才是真正的"光照增强"** |

**⚠️ 一个必须理解的点**：PlantVillage 的叶片是**实验室受控光照**下拍的。
单纯贴到野外背景上（S1），**叶片的颜色统计仍然是实验室的** ——
所以 **S1 补的是背景多样性，不是光照多样性**。
想要光照多样性，**必须做 S2**。

**所以"要不要把叶子模拟成背景的光照"这个问题的答案是：做成 S2，和 S0/S1 对比。
不用纠结，让实验回答。** 而且文献里明确**没有人做过** image harmonization 在植物病害上的应用
（见 `图像合成数据增强综述.md` 第 6 节），所以这一步本身就有可写的价值。

### 1.4 两条硬约束（重复强调，违反了实验就废）

1. **合成数据必须对称地施加在两边**（普通版和四元数版用**完全相同**的合成数据）
   → 这样合成就从"混淆变量"变成"受控条件"
2. **绝不能让合成图覆盖 held-out 域**（逆光 / 傍晚暖光）
   → 合成只能模拟**训练域（强光 / 阴天）**范围内的光照

## 2. 重新提出的研究问题

### 2.1 为什么原假设要改

| | 内容 | 状态 |
|---|---|---|
| **原假设** | 四元数卷积能给模型带来对光照的**内建不变性** | ❌ **理论推导表明不成立**（我自己的推导 + 数值验证） |
| **修正假设** | 四元数卷积对通道混合施加的**结构约束**（4 维子空间 vs 普通卷积的 9 维任意矩阵），是一种**归纳偏置**。它在**训练光照 ≠ 测试光照**时，是帮助泛化还是有害？ | ✅ **有正反两种可能，且没人回答过** |

**这个框架的巨大优势：无论结果是什么，都是有效结论。**

| 实验结果 | 结论 |
|---|---|
| 四元数版跨域衰减**更小** | 结构约束起到**正则化**作用，减少了对训练光照的过拟合 |
| 两版**差不多** | 该归纳偏置在光照域上不起作用，说明**光照泛化需要别的手段**（如数据增强） |
| 四元数版**更差** | 约束过强，**表达能力不足**，学不到足够的光照不变特征 |

**本科毕设最怕"没结果"。这个框架保证你有结果。**

### 2.2 定稿的研究问题

**主问题**：

> **四元数卷积这一结构约束，对轻量卷积神经网络在跨光照域叶片病害识别中的泛化能力有何影响？**

**子问题**：

1. 相比**参数量对齐**的普通卷积基线，四元数卷积在未见光照域上的性能衰减是否更小？
2. 这种影响在**不同光照轴**（色温/对比度 vs 强度/方向性）上是否一致？
   （3. 节的理论分析给出了可检验的预测）
3. 合成数据增强（S1 背景替换 / S2 背景替换+光照迁移）能否缩小跨光照域的性能差距？
   它与四元数结构约束的作用**是否叠加**？

### 2.3 三个贡献点（按重要性）

| # | 贡献 | 为什么算贡献 |
|---|---|---|
| **1（主）** | **首次系统检验四元数卷积在光照域泛化上的表现**，并给出"什么条件下有用/没用"的分轴分析 | 文献空白（8 组以上关键词检索确认）；且框架保证有结果 |
| **2（次）** | 一套**光照分层评测协议**：按光照分域 + 按遮挡分层 + 用 ground-truth 框隔离检测器偏置 + 参数量对齐对照组 | 方法学工作，可直接复用；文献里没有这么做的 |
| **3（次）** | **合成增强的消融**（S0/S1/S2），特别是 S2 的光照迁移 | 文献里明确没人做过 harmonization 在植物病害上的应用 |

### 2.4 两阶段方案的理由（补齐文献）

| 理由类型 | 内容 |
|---|---|
| **技术** | YOLO 是非顺序型（C2f 内部有通道切分），四元数化工程量与风险大。**有实测依据**：`quaternion_feasibility.py` 证明 C2f 的 `chunk(2,1)` 会**静默**破坏四元数结构 |
| **文献** ⭐ | **HODRF, Iwano et al., AGRETA 2024**, DOI `10.1109/agreta61912.2024.10948896` —— 原文明确论证：目标检测无法在"健康/无可检测部位"数据上显式训练，加一个分类阶段可以补偿这个弱点 |
| **工程** | 端侧部署时两阶段可分离：检测器固定，分类器可独立替换/升级/量化 |
| **个人偏好** | 可以提，但放最后，**不作为主要论据** |

## 3. 理论预测（你的实验可以先验证这个）

我的推导给出的可检验预测（见 `论证链与文献支撑.md` 2.5.2）：

| 光照轴 | 对"相对色彩关系"的破坏 | **预测四元数卷积有帮助吗** |
|---|---|---|
| **色温偏移**（傍晚暖光） | 破坏（R:G:B 比例改变） | ⚠️ **理论上无内建优势**，但结构约束可能在训练中起作用 |
| **对比度下降**（阴天） | 部分破坏 | ⚠️ 同上 |
| **纯强度变化**（强光） | **完全不破坏**（R:G:B 不变） | ❌ **预测无优势** —— 比例没变，通道耦合没有用武之地 |
| **饱和截断**（强光） | **不可逆破坏** | ❌ 信息已丢，任何算子都救不回来 |
| **空间光照梯度**（逆光） | 局部破坏 | ❌ 需要**空间**建模，不是逐点通道建模能解决的 |

**所以分轴报告时**：

- 如果"**强光域两版差不多**" → **不是失败，是理论预测被验证**，这本身就是结果
- 如果"**傍晚暖光域四元数版明显更好**" → 支持结构约束假设
- **这样的分轴分析比一个笼统的平均值有说服力得多。**

## 5. 三个必须避开的陷阱（重复强调）

| | 陷阱 | 解法 |
|---|---|---|
| 🔴 | **YOLO 的框会污染分类器的跨域评估**。YOLO 在逆光下漏检严重 → 分类器只能看到"恰好被找到的叶子" → 这个子集有偏 → **测到的衰减被低估，且很难察觉** | 分类器的跨光照实验**用 ground-truth 框**；YOLO 的 recall 单独报；端到端再报一个，并说明差距来自哪里 |
| 🟠 | **光照标签噪声 + 分类器可能"偷看"背景**（用天空/土壤判断光照 → 产生虚假的域划分） | 报**混淆矩阵**而不只是准确率；做高置信子集敏感性分析；人工校验时记录"判断光照主要靠什么线索" |
| 🟡 | **"SAM 算遮挡率做硬对齐"性价比低**：要丢大量样本，而逆光照片的典型特征就是背景过曝，硬对齐会把逆光样本筛得面目全非 | 改成**只记录、不筛选，评估时按遮挡等级分层报告** —— 不丢数据、混淆照样被控制、还多一个分析维度 |

## 6. 一页话总结

> **你的逻辑链没有问题。** 真正被推翻的只是"四元数有内建光照不变性"这个**强版本**的假设；
> 换成"四元数的结构约束作为归纳偏置，影响跨光照泛化"这个**弱版本**，课题立刻站得住，
> 而且**无论结果好坏都有结论**。
>
> **"验证假设"和"提升模型"不矛盾** —— 它们是同一张 6 格表的横向和纵向。
> 合成增强是**训练手段**（两边对称施加），分域测试是**评估协议**（不能被污染）。
>
> **唯一真正紧迫的事是 P0**：先确认数据够不够分域、普通版的衰减够不够大。
> **这两件事不做，后面全是空中楼阁。**
