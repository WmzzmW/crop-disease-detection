# yolov8-quat —— 新方向工作目录

## 课题

**基于四元数卷积改进 YOLOv8 的大田作物叶片病害光照鲁棒性检测研究**

## 与老方向的区别

老方向（见 `../archive/`）是**分类**任务：在 PlantVillage 受控实验室图像上做病虫害分类，
并附加对抗样本防御。新方向在多个关键点上不同：

| | 老方向 | 新方向 |
|---|---|---|
| 任务 | 图像分类（38 类） | **目标检测**（定位 + 分类） |
| 模型 | MobileNetV3-Small | **YOLOv8** + 四元数卷积 |
| 数据 | PlantVillage（受控条件、单叶居中） | **大田**（背景杂乱、多叶、遮挡） |
| 核心挑战 | 对抗样本 | **光照鲁棒性** |
| 部署 | 移动端 App | 待定 |

因此 `../archive/` 里的代码**绝大部分不可复用**——任务类型（分类→检测）、
输入条件（实验室→大田）、模型架构（CNN→四元数卷积）都变了。

## 目录约定

```
yolov8-quat/
├── docs/            课题相关文档（学校模板等），纳入版本库
├── datasets/        数据集（不进版本库，见 ../.gitignore）
├── runs/            训练输出（不进版本库）
└── ...              代码
```

- **数据集**放 `datasets/` 或 `data/`，两者都已在 `.gitignore` 里全局忽略，不会误提交
- **模型权重**（`*.pt` / `*.onnx` / `*.engine` 等）同样已忽略
- 想强制提交被忽略的文件用 `git add -f <路径>`
